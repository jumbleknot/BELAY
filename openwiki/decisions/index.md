- [ADR-0005 — operator-tool MCP servers, local stdio, shipped as Claude Desktop Extensions](adr-0005-operator-tool-mcp-servers.md) - The maintainer's 2026-11-25 approval (feature 014, M1 and M2) of a second MCP server class in constitution 1.1.0 — local stdio servers a desktop assistant launches for one operator, Node or Python with no Dockerfile — with its tailnet transport rule and host-log audit rule, the .mcpb packaging through a hoisted pnpm deploy, the three exact-pinned packages, the mcp-servers/* workspace entry, and why a remote or bridged server was rejected.
