# Files

- [ADR-0001 — pnpm and Nx only](adr-0001-pnpm-and-nx-only.md) - Why pnpm is the only JavaScript package manager and Nx the only task runner in BELAY — enforced by preinstall and a single packageManager pin, with CI's whole check surface as two Nx targets — the operator-CLI exception, and why any other language toolchain is a new decision rather than a default.
- [ADR-0002 — the session maintains the wiki, with no generator](adr-0002-session-maintained-wiki.md) - Why BELAY's openwiki/ bundle is refreshed by the coding session in the same PR as its source, fingerprinted and gated by V17, rather than regenerated by a paid model in CI — MCM's measured $167.80 for 39 pages in 30 days — and the constraint it puts on resources (one file no bot rewrites).
- [ADR-0003 — the dev container in a dedicated Docker Sandbox microVM](adr-0003-docker-sandbox-devcontainer.md) - Why BELAY's dev container runs in its own Docker Sandbox microVM with host-side default-deny egress and a CI-published, digest-pinned toolchain image — the rejected alternatives (sharing MCM's VM, a larger VM, Docker-in-Docker, reusing MCM's image) and what it costs (no in-sandbox image builds, worktrees that do not survive a rebuild, pins that never move by themselves).
- [ADR-0004 — a self-hosted Renovate bot proposes updates](adr-0004-renovate-dependency-bot.md) - The maintainer's 2026-11-23 approval of a self-hosted Renovate bot on Forgejo Actions to keep BELAY's SHA, digest, lockstep and lockfile pins current — propose only, never automerge, a human merges — what is fixed now and what is left to the feature spec (backlog item 47), and why the bot is not done until its health loop (backlog item 48) is.
