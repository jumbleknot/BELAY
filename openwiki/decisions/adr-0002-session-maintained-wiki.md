# ADR-0002 — the session maintains the wiki, with no generator

Accepted when the bundle was created (2026-11-22) and back-filled on 2026-11-23. It adopts
MovieCollectionManager's ADR-0004. A derived page records the hash of its one source. Rule V17, in the
required `guardrails` check, fails a PR that changed the source without refreshing the page, and
`wiki-refresh.mjs` does the bookkeeping offline. MovieCollectionManager retired its CI generator after
measuring $167.80 over 106 runs in 30 days for 39 distinct pages, with a cost floor that tuning could
not remove.

## Gotchas

- **A `resource` is one file that no bot rewrites.** A bot PR has no session present to refresh a page,
  so a lock file, workflow or manifest can never be cited. This bites as soon as the dependency bot
  ([ADR-0004](adr-0004-renovate-dependency-bot.md)) is opening PRs.
- **V17 proves a refresh was recorded, not that it is right.** Read `--diff` before `--record`.
- The procedure is in [wiki maintenance](../process/wiki-maintenance.md).
